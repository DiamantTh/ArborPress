# Theme reference files

This source-checkout directory is not a runtime discovery location. ArborPress
loads built-in themes from `arborpress/themes/` and operator themes only from
the active prefix's `instance/themes/` directory. Files here are reference
material; copy a theme deliberately into `instance/themes/<theme-id>/` before
it becomes available to an ArborPress instance.

The current manifest, inheritance, asset, and override contract is documented
in [`docs/themes.md`](../../docs/themes.md).
